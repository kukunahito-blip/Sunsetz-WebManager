# 🌅 Sunsetz WebManager

Sunsetz WebManager est un gestionnaire de sites web élégant et performant conçu avec **Electron**. Il permet de centraliser, vérifier et accéder à vos sites favoris via une interface fluide et animée.

## ✨ Fonctionnalités

* **Gestion centralisée** : Ajoutez et gérez vos URLs en quelques clics.
* **Vérification en temps réel** : L'application vérifie la disponibilité du site avant de l'ajouter.
* **Interface Intuitive** : Design sombre (Dark Mode) avec des animations fluides pour une expérience utilisateur optimale.
* **Multi-plateforme** : Disponible sur Windows, macOS et Linux.

---

## 🚀 Installation

Choisissez le guide correspondant à votre système d'exploitation.

### 🪟 Windows
Nous proposons deux formats pour Windows :

#### 1. Version Portable (Le plus simple)
* Téléchargez le fichier `WebManager-App-X.X.X.exe`
* Ouvrez le fichier pour lancer l'app.

####  2. Installation Complète

* Téléchargez le fichier `WebManager-App-Setup-X.X.X.exe`.
* Lancez l'installateur et suivez les étapes.
* L'application sera disponible sur votre bureau et dans le menu démarrer.

### 🍎 macOS
Pour macOS, vous trouverez un fichier `.dmg`.
1. Téléchargez le fichier `WebManager-App-X.X.X.dmg`.
2. Ouvrez le fichier.
3. **Glissez-déposez** l'icône de WebManager vers votre dossier **Applications**.
4. **Note de sécurité** : Comme l'application n'est pas signée par un certificat Apple payant, vous devrez peut-être faire un *Clic droit > Ouvrir* la première fois ou aller dans *Réglages Système > Confidentialité et sécurité* pour autoriser l'ouverture.

### 🐧 Linux
Nous proposons deux formats pour Linux :

#### 1. AppImage (Le plus simple)
* Téléchargez le fichier `.AppImage`.
* Faites un clic droit sur le fichier > **Propriétés** > **Permissions**.
* Cochez **"Autoriser l'exécution du fichier comme un programme"**.
* Double-cliquez pour lancer l'app.

#### 2. DEB (Pour Debian/Ubuntu)
* Téléchargez le fichier `.deb`.
* Ouvrez un terminal dans le dossier de téléchargement.
* Tapez la commande : `sudo dpkg -i sunsetz-webmanager_X.X.X.deb` (ou utilisez l'installateur de paquets graphique).
